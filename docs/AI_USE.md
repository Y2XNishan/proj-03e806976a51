# AI-use disclosure

An AI coding assistant created the plan, scaffold, Elexon client, cache, point-in-time selection logic, React dashboard, tests, snapshot export/validation, Docker and Vercel configuration, and documentation. The assistant inspected Elexon's official OpenAPI schema and live stream responses, ran a real historical refresh, and exported its records into a checksum-verified read-only deployment asset. Test fixtures contain synthetic, explicitly labeled records; production endpoints and dashboard read only source-backed Elexon data. The reported historical metrics were calculated from those records, not generated as sample numbers. The user configured and verified the Vercel deployments; the assistant later performed read-only HTTP checks of the live frontend and API summary. Backend and frontend tests and a local build were run. The user also verified the Docker Compose build, startup, source-backed API response, and dashboard date filter on Windows; the assistant did not rerun Docker during this documentation update. Human review of the assumed decision cutoff, Elexon source coverage, metric interpretation, and future snapshot changes remains necessary before using the dashboard for purchasing decisions.
